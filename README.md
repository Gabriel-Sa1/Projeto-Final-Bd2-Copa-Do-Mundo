# 🏆 Projeto Final BD2 — Copa do Mundo FIFA

## 📋 Visão Geral

Este repositório reúne toda a documentação e o código-fonte do projeto de banco de dados relacional desenvolvido para a disciplina de **Banco de Dados 2**, abrangendo desde a modelagem conceitual e lógica até os scripts SQL de criação, população e consulta.

---

## 🎯 O Problema e a Solução

Encontrar dados históricos e estatísticos precisos, confiáveis e centralizados sobre a Copa do Mundo da FIFA costuma ser um desafio — as informações geralmente estão dispersas em diferentes portais e formatos pouco estruturados.

Este banco de dados propõe uma base relacional organizada e de fácil consulta, com foco nos **jogadores e em seus desempenhos individuais durante a competição**. A estrutura atende desde torcedores e entusiastas até jornalistas esportivos e analistas de desempenho de clubes interessados em avaliar atletas no torneio.
